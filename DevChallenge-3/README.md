# Newsletter Landing Page

A responsive newsletter subscription landing page built as part of a devChallenges frontend challenge.

## 🚀 Overview

This project is a simple newsletter signup page where users can enter their email address and subscribe to receive updates about new collections, exclusive deals, and special offers.
