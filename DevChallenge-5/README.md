# Testimonial Page

A responsive testimonial page built with HTML and CSS based on a design challenge.

## 🚀 Live Demo

[View Live Demo](https://triveni-3124.github.io/WEB-DEVELOPMENT/DevChallenge-5/index.html)

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- Google Fonts
- SVG assets

## 📚 What I Practiced

- Structuring a webpage using semantic HTML
- CSS Flexbox layout
- `flex-direction`
- `align-items`
- `justify-content`
- `gap`
- Width, margin, and padding
- Creating circular elements with `border-radius`
- Positioning cards using parent-child Flexbox relationships
- Working with images and SVG assets
- Basic typography and spacing

## 💡 What I Learned

This project helped me understand how Flexbox controls the relationship between a parent container and its children.

I also practiced breaking a design into smaller sections and building each section step by step instead of trying to create the entire page at once.
