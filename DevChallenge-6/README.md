# Business Blog Card

A responsive business blog card built using HTML and CSS based on a DevChallenges design.


## Live Demo

[View Live Demo](https://triveni-3124.github.io/WEB-DEVELOPMENT/DevChallenge-6/index.html)

## Repository

[View Repository](https://github.com/triveni-3124/WEB-DEVELOPMENT)


## Features

- Responsive card layout
- Hero background image
- Custom Google Fonts
- Circular author avatar
- Responsive design using CSS media queries
- Clean and simple layout

## Built With

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts

## What I Practiced

- Centering elements using Flexbox
- Working with parent and child elements
- Using background images
- Creating circular images with `border-radius`
- Styling text and dividers
- Making the card responsive with media queries
