# Minimal Blog Card

A responsive minimal blog card built as a DevChallenges project.

## Demo

[Live Demo](https://triveni-3124.github.io/WEB-DEVELOPMENT/DevChallenge-2/)

## Repository

[GitHubRepository] (https://github.com/triveni-3124/WEB-DEVELOPMENT)

## What I learned

- How to create and style a card layout using HTML and CSS
- How to use Flexbox to center content
- How to work with spacing, margins, and padding
- How to style images and text
- How to create a responsive design using media queries

## Built with

- HTML5
- CSS3
- Flexbox
- Media Queries

## Features

- Responsive blog card
- Styled image and category tag
- Blog title and description
- Author information
